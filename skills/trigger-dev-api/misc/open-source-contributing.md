# Contributing

> Source: https://trigger.dev/docs/open-source-contributing

Go to our [GitHub repository](https://github.com/triggerdotdev/trigger.dev)
 and open an issue or a pull request. We are always looking for contributors to help us improve Trigger.dev. You can contribute in many ways, including:

*   Reporting bugs
*   Suggesting new features
*   Writing documentation
*   Writing code
*   Reviewing code
*   Translating the app
*   Sharing the app with others
*   Giving feedback
*   And more!
