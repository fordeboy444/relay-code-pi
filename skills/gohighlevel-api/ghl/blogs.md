Documentation for Blogs

[📄️Check url slug\
-----------------\
\
The 'Check url slug' API allows check the blog slug validation which is needed before publishing any blog post. Please use blogs/check-slug.readonly. you can find the POST ID from the post edit url.](https://marketplace.gohighlevel.com/docs/ghl/blogs/check-url-slug-exists)

[📄️Update Blog Post\
-------------------\
\
The 'Update Blog Post' API allows you update blog post for any given blog site. Please use blogs/post-update.write](https://marketplace.gohighlevel.com/docs/ghl/blogs/update-blog-post)

[📄️Create Blog Post\
-------------------\
\
The 'Create Blog Post' API allows you create blog post for any given blog site. Please use blogs/post.write](https://marketplace.gohighlevel.com/docs/ghl/blogs/create-blog-post)

[📄️Get all authors\
------------------\
\
The 'Get all authors' Api return the blog authors for a given location ID. Please use 'blogs/author.readonly'](https://marketplace.gohighlevel.com/docs/ghl/blogs/get-all-blog-authors-by-location)

[📄️Get all categories\
---------------------\
\
The 'Get all categories' Api return the blog categoies for a given location ID. Please use 'blogs/category.readonly'](https://marketplace.gohighlevel.com/docs/ghl/blogs/get-all-categories-by-location)

[📄️Get Blog posts by Blog ID\
----------------------------\
\
The 'Get Blog posts by Blog ID' API allows you get blog posts for any given blog site using blog ID.Please use blogs/posts.readonly](https://marketplace.gohighlevel.com/docs/ghl/blogs/get-blog-post)

[📄️Get Blogs by Location ID\
---------------------------\
\
The 'Get Blogs by Location ID' API allows you get blogs using Location ID.Please use blogs/list.readonly](https://marketplace.gohighlevel.com/docs/ghl/blogs/get-blogs)
